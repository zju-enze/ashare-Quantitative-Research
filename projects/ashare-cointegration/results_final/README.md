报告日期：2026-10-22。范围为已完成的 V1/EG、V2.1/DH 历史研究，以及 2026-10-21 完成的共同 DGP 补充实验。这是本轮综合报告入口；“最终”表示本轮交付收尾，不表示全部统计假设或真实市场错误控制已通过验证。

**V1 保留 110 对 L2-Holm 名义发现，V2 保留 0 对 GLOBAL-Holm 名义发现。补充实验中，主规格 EG/DH 一阶误拒率为 5.54%/5.06%，慢回复备择功效为 16.28%/8.56%。两条路线目前均不能据此宣称全市场真实 FWER 已控制在 5%。**

## 实际市场结果与补充实验分开解释

|维度|V1 / EG|V2 / DH|
|---|---|---|
|原市场输入与预检|2021—2025 复权价格水平；逐股 ADF 入场门槛|同一冻结输入与 ADF 入场门槛|
|原市场工作规格|EG，常数项，AIC 选阶|DH 两方程联合检验，固定 7 阶|
|原主校正域|各 L2 行业分别 Holm，名义 5%|完整候选 GLOBAL-Holm，名义 5%|
|原市场主发现|110 对，其中 T 57、C 53；9 对非正 beta 保留|0 对|
|统一校正域的历史对照|GLOBAL-Holm 7 对；L2-Holm 110 对|GLOBAL-Holm 0 对；L2-Holm 0 对|
|原校准结论|18,080 面板完成；N1/N5/N6/N7 等机制暴露失准|18,000 正式面板完成；整体 inconclusive|
|补充主比较|对数价格、无逐股 ADF 门槛、固定 1 阶|同一路径、同样输入与门槛、固定 1 阶|

原市场共 2,984 股、67,678 个候选位置；两方法各有 42,121 个有效检验、25,557 个预检占位，数值占位均为 0。补充实验没有重算这些市场候选。因此，110 与 0 仍是原价格水平规格的结果，不是新对数价格规格的市场发现数。

## 补充实验的主要结果

四情景各 5,000 条独立两股票路径，合计 20,000 条路径、80,000 次检验；工程样本另计。主水平 5%。表中区间为逐格 95% 双侧 Clopper–Pearson 区间；差值和配对 MCSE 的单位为百分点。

|情景与指标|EG 固定 1 阶 [95%区间]|DH 固定 1 阶 [95%区间]|EG − DH|配对 MCSE|
|---|---:|---:|---:|---:|
|主 DGP：无协整，误拒率|5.54% [4.92, 6.21]|5.06% [4.47, 5.70]|+0.48|0.423|
|主 DGP：慢回复协整，功效|16.28% [15.27, 17.33]|8.56% [7.80, 9.37]|+7.72|0.574|
|个股 ν=3.5：无协整，误拒率|6.78% [6.10, 7.51]|4.62% [4.05, 5.24]|+2.16|0.431|
|个股 ν=3.5：慢回复协整，功效|16.48% [15.46, 17.54]|8.12% [7.38, 8.91]|+8.36|0.557|

![补充实验拒绝率与逐格95%区间](../results_revision/pair_comparison/supplementary_rejection_rates.png)

在这一预定慢回复 DGP 中，EG 的检出率较高，DH 对所考察厚尾扰动的误拒率较稳定。主 DGP 的误拒率区间包含 5%，不能据此证明误拒率不超过 5%。厚尾情景下 EG 一阶区间整体高于 5%；DH 的实测表现也不能扩展成对所有无四阶矩过程的有效性保证。

原工作规格在同一主备择下的功效为 EG-AIC 16.14%、DH-7 8.04%。把 DH 改为 1 阶只将本批功效提高到 8.56%，与同阶 EG 的差距仍存在。旧校准的大面板功效与本轮单对功效具有不同分母、DGP、输入与门槛，不能直接相减。
