# A股同业股票对的协整关系识别
## V1与V2方法验证阶段报告

2026-10-22

**研究主问题：在预先限定的同业股票对中，哪些配对具有协整证据？这些证据来自什么检验、经过什么多重校正，适用范围和限制是什么？**

这项研究最终需要交付可以逐对追溯的证据清单，为后续组合研究提供依据。当前已经完成的是识别流程中的方法验证：在答案已知的模拟数据中，检查 V1/EG 和 V2/DH 会误报多少不存在的关系，以及能找出多少真正存在的关系。修订方案下的真实股票对清单尚未生成。

## 从研究问题到当前实验

同一行业的两只股票可能一起上涨，但它们之间的差异仍可能越走越远。协整关注更严格的关系：两条价格序列各自可以持续漂移，某个固定加权组合却保持稳定的统计特征。我们使用对数价格研究这种组合关系；“具有协整证据”表示在给定样本和统计假设下的检验结论，不等于保证未来回归或交易盈利。

用于估计关系和设定方法的历史区间称为形成期，本研究取 2021—2025 年。研究基础包括 2,984 只股票和冻结的 67,678 个同业候选对。候选数量描述待识别范围，不是本次修订方案已经检验并确认的股票对数量。

|识别流程中的环节|需要回答的问题|目前位置|
|---|---|---|
|数据与候选范围|哪些股票可比较，采用什么价格与行业口径？|已有冻结数据与候选；适用范围见[数据说明](../DATA_CONTRACT.md)|
|检验方法验证|检验会误报多少，会漏掉哪些真关系？|本报告：共同模拟设计已完成|
|同时检验很多股票对|怎样对整批检验作校正，控制错误发现？|修订方案的共享股票面板校准及校正范围尚未确定并完成|
|真实股票对证据清单|具体哪些股票对通过预定检验与校正？|尚未按修订方案生成|
|组合与交易应用|已识别关系在样本外能否使用？|后续阶段，不作为当前识别标准|

因此，EG 与 DH 的比较服务于股票对识别。比较的目的，是判断我们准备使用的工具是否可信，以及怎样解释它们找出或遗漏的关系。

## 读懂两条方法路线

V1 使用 **Engle–Granger 检验（EG）**：先估计两只股票的对数价格关系，再检查估计价差是否平稳。V2 使用 **Demetrescu–Hanck 检验（DH）**：本研究采用两方程联合统计量，对波动随时间变化的问题作不同处理。两条路线都保留其各自的适用条件。

真实股票对没有可直接查阅的协整标准答案，因此我们先用**数据生成过程（DGP）**产生答案已知的模拟价格。其参数参考形成期市场数据。主设定包括没有协整和存在慢回复协整两种情况；另将个股冲击改得更厚尾，考察极端变动更常见时的表现。每种情况生成 5,000 组价格路径。

两方法检验同一路径，主规格都固定 1 阶，即使用一期滞后变化描述短期动态。主比较不设逐股 ADF 入场门槛，EG 内部检查价差的 ADF 仍保留。AIC 自动选阶和 DH 固定 7 阶作为辅助对照，完整说明放在[术语与方法附录](METHODS_AND_GLOSSARY.md)。

## 当前证据说明什么

**误报率**是在真实答案为“没有协整”时，仍被判为有协整证据的比例。**检出率（功效）**是在真实答案为“有协整”时，被正确找到的比例。下表采用 5% 名义检验水平；括号内为逐格 95%置信区间。

|模拟情景与指标|EG-fixed-1|DH-fixed-1|
|---|---:|---:|
|主设定：没有协整，误报率|5.54% [4.92%, 6.21%]|5.06% [4.47%, 5.70%]|
|主设定：存在慢回复协整，检出率|16.28% [15.27%, 17.33%]|8.56% [7.80%, 9.37%]|
|厚尾设定：没有协整，误报率|6.78% [6.10%, 7.51%]|4.62% [4.05%, 5.24%]|
|厚尾设定：存在慢回复协整，检出率|16.48% [15.46%, 17.54%]|8.12% [7.38%, 8.91%]|

主设定下，两方法的误报率区间都包含 5%，但不能由此证明真实误报率不超过 5%。更明显的识别困难是慢回复关系的漏检：5,000 组确有协整的价格中，EG 检出 814 组，DH 检出 428 组。EG 比 DH 高 7.72 个百分点，同路径比较的模拟标准误为 0.574 个百分点；两者仍漏掉了大部分本情景中的真关系。

厚尾对照揭示了另一项影响名单质量的风险。EG 的误报率区间整体高于 5%；DH 在该情景中误报较少，但此对照超出其高阶矩假设范围。因此，结果既不支持只凭较高检出率选方法，也不支持只凭发现少就认定结果可靠。

这些结论来自一个预定慢回复参数点，而非所有可能的协整关系。5,000 次单对模拟也没有验证同时检验完整候选集合时的错误控制。下一步需要把方法放入一致的股票面板和校正方案中，再对真实候选逐对生成证据；不能用模拟中的正确率替代这一步。
