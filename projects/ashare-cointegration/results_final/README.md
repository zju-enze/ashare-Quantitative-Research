## 如何理解这些证据

协整关注的是：两条价格序列各自可以持续漂移，某个固定加权组合却保持稳定的统计特征。本研究检验对数价格的关系。“具有协整证据”是固定数据、方法和假设下的统计结论，不等于保证未来回归或交易盈利。

EG（Engle–Granger）先估计两只对数价格的关系，再检查价差是否平稳。DH（Demetrescu–Hanck）在本研究中采用两方程联合统计量，对波动变化作不同处理。固定1阶表示采用一期滞后变化描述短期动态，不代表已经证明市场的最优阶数是1。

Holm校正把一组检验一起处理，以限制偶然错误发现。**每个行业分别校正后的发现总数，不能直接解释为全市场5%错误控制；全局校正也不能修复不适用的单项p值。** 本次只是执行并列的名义口径，完整共享股票图的校准仍未完成。

I(1)指价格水平不平稳、差分后平稳。逐股对数价格ADF诊断只作提示，没有用于筛除股票对。EG行业内284对中有148对至少一股诊断不相容，DH行业内11对中有4对；EG全局21对中也有11对带警示。诊断相容不证明I(1)，有警示的结果也没有被偷偷删除。这些信息见[发现清单诊断](../results_revision/market_20261023/discovery_diagnostics.csv)。

DH一阶的43个数值不可用位置均为早期递归估计缺乏识别条件，保留p=1及完整家族规模。完整原因和数据表现见市场汇总；没有用7阶结果替换1阶结果。

## 模拟验证怎样帮助解释市场清单

已完成的共同数据生成过程（DGP，即产生已知答案的模拟价格的规则）共有20,000条路径、80,000次检验。主设定下，EG/DH误报率分别为5.54%/5.06%，慢回复检出率为16.28%/8.56%；厚尾对照下误报率为6.78%/4.62%。

误报率是没有协整时被误判的比例，检出率是确有协整时被找到的比例。它们不是市场清单中真假关系占比。上述模拟提示EG的厚尾误报风险和DH的慢回复漏检风险；既不能以发现更多证明更准确，也不能以发现少断言市场缺乏协整。

两股票独立模拟仍不能代替整个共享股票候选图的校准。当前已经完成真实候选计算、名义校正、清单及解释；整体错误控制验证、样本外组合与交易评价仍是未完成的研究内容。
