# A股同业股票对协整证据识别：第一阶段最终交付

建议首批探索新农开发—万向德农、皖新传媒—南方传媒、小崧股份—海洋王、陕国投A—浙江东方、张家港行—紫金银行、农业银行—邮储银行。它们提供不同的证据和分歧，选择理由在最终报告第5节逐对说明，不按最小p值排序。
