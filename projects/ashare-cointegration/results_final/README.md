# V1 / V2 正式实验结果

报告日期：2026-10-22。本正式版以已讨论并执行的共同对数价格 DGP 方案为唯一实验设计：V1 为 EG，V2 为 DH；原设计的实验独立归档。

**主 DGP 下，V1/EG 与 V2/DH 固定 1 阶的误拒率为 5.54%/5.06%，慢回复备择功效为 16.28%/8.56%。厚尾对照中，EG 的误拒率升至 6.78%，DH 为 4.62%。结果显示本条件下的检出能力与误拒率差异。**

## 正式设计

|维度|V1 / EG|V2 / DH|
|---|---|---|
|共同输入|同一条两股票对数价格路径|同一路径|
|共同 DGP|empirical-pair-dgp-1：市场参数估计、协整真值由结构定义|相同|
|逐股 ADF 入场门槛|无；保留 EG 残差 ADF|无|
|主检验|含截距的 EG，两步残差检验|DH 两方程联合 Q|
|主比较选阶|固定 1 个残差差分滞后|固定 1 个价格差分滞后向量|
|选阶敏感性|EG-AIC|DH 固定 7 阶|
|主 / 辅助显著性水平|5% / 1%|5% / 1%|
|误差与功效单位|单对独立路径；无跨股票家族多重校正|相同|
|正式工作量|20,000 条路径，两规格 40,000 次检验|同 20,000 条路径，两规格 40,000 次检验|

四情景各 5,000 条路径：主 DGP 的无协整/慢回复协整，以及仅将个股 ν 改为 3.5 的两项厚尾对照。每条路径同时用于四规格，总计 80,000 次检验。主 DGP ν=(6,7,4.5)，ρ≈0.03037，备择 φ≈0.99292；1,212 个观测、预热 2,000。工程样本另计，不进入正式分母。

## 主比较结果

区间为逐格 95% 双侧 Clopper–Pearson 区间。无协整行报告误拒率，协整行报告功效；配对差异按同一路径计算。

|情景|V1：EG 固定 1 阶 [95%区间]|V2：DH 固定 1 阶 [95%区间]|V1 − V2（百分点）|配对 MCSE（百分点）|
|---|---:|---:|---:|---:|
|主 DGP：无协整|5.54% [4.92, 6.21]|5.06% [4.47, 5.70]|+0.48|0.423|
|主 DGP：慢回复协整|16.28% [15.27, 17.33]|8.56% [7.80, 9.37]|+7.72|0.574|
|个股 ν=3.5：无协整|6.78% [6.10, 7.51]|4.62% [4.05, 5.24]|+2.16|0.431|
|个股 ν=3.5：慢回复协整|16.48% [15.46, 17.54]|8.12% [7.38, 8.91]|+8.36|0.557|

![四情景拒绝率及逐格95%区间](../results_revision/pair_comparison/supplementary_rejection_rates.png)

主 DGP 的两种一阶误拒率区间均包含 5%，不能据此证明误拒率不超过 5%。EG 在预定慢回复备择下的检出率高于 DH；厚尾下 EG 一阶的误拒率区间整体高于 5%，需要与功效一起解释。ν=3.5 超出 DH 的矩假设范围，实测表现不能当作普遍理论保证。

## 选阶敏感性与解释边界

同一主备择下，EG-AIC 功效为 16.14%，DH-7 为 8.04%。DH 改为 1 阶后功效为 8.56%，同阶方法间差距仍存在。本设计没有逐股门槛和家族多重校正，因此不能将此处的低检出率归因于这两个环节。

四情景不是完整功效曲线。当前结果属于两股票路径的条件性方法比较，尚未扩展到完整共享股票图、真实市场检验或交易评价。
