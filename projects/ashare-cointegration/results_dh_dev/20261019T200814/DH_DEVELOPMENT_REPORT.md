# DH 2018 开发验证结果与本机预算

日期：2026-10-19。结论：工程实现与本次合成验证完成；统计验收未执行。

## 实现范围

独立新增 src/engine_dh.py、tests/test_engine_dh.py 和 scripts/validate_dh_development.py。保持 v1 文件、结果与入口不变。采用正确的 DH 2018 两方程联合统计量，递归去均值与前缀残差，7 个滞后差分向量，原始 T 作为协方差分母，Q 的 chi-square(2) 解析尾概率，完整家族 GLOBAL-Holm。

名义 alpha=0.05；0.10 仅登记为未来校准的最大 FWER 容忍值，本轮没有作“通过 5% / 容忍 10%”统计判定。无 defactor，无 bootstrap，N1 未纳入新工程面板。模型仍以无额外确定性漂移为条件。

## 验证证据

- 原 v1 的 16 项单元测试通过；新 DH 的 7 项测试通过。
- 递归残差与逐前缀直接计算相符；追加未来观测不改变此前残差。
- FWL 实现与完整 Z'W IV 矩阵解在 N0/N6/A0/M1、p=0/7 的夹具上相符，包括系数、t、Q 和 p。
- 平移、正比例缩放不改变 Q；退化输入保留不可用状态；GLOBAL 校正保留预检占位；单/双进程统计结果逐位一致。
- 75 个 S0 冒烟面板加 9 个计时面板，共 84 面板、7200 次 DH 系统检验，全部有完整结果，数值不可用计数 0。
- 7200 行结果的候选键无重复，84 个家族的 Holm 调整与拒绝标记按独立排序公式复核一致。
- 主批次（含初始 22 项测试）用时 78.91 秒。增加的第 7 项 DH 测试及当前 DH 套件另有 tests_dh_followup.txt 记录。

这不是作者代码对照或论文 5000 次模拟的复现；本轮核对的是原文公式及工程路径。

## 冒烟观察：不能当作校准结论

每个机制只有 5 个独立面板，每面板 12 对。配对共享股票，不能把 60 对当成 60 个独立重复。

|机制|观察|
|---|---|
|N0、N2、N3、N4、N5、N6|各自 0/5 面板发生 GLOBAL-Holm 假发现|
|N7|1/5 面板发生假发现，共 1 对|
|A0 / A1 / A2 / A3|各 60 个真备择中分别发现 60 / 57 / 51 / 42 对|
|A4 / A5|各 60 个慢回复真备择中分别发现 0 / 1 对|
|M0 / M1|各 20 个真备择中分别发现 7 / 9 对；未发现真零被拒绝|

N7 错误案例：S0/N7/repetition=10000，S00000__S00001，Q=14.115129992577522，原始 p=0.00086087176984，GLOBAL-Holm p=0.0103304612380806。独立完整矩阵参考的 Q=14.11512999257753；未发现公式实现差异，不据此改阶数或删除机制。

N6 的 60 对中有 35 对被预检排除；原始单项名义拒绝率约 11.7%，与预检后的 GLOBAL 结果需分开阅读。样本太少，不能宣布 DH 已控制 size，也不能仅据 N7 的 1/5 宣布超过 10% 容忍界。慢回复备择的检出能力仍是后续开发需要检查的问题。

## 本机计时

机器：Intel Core i9-14900HX，32 逻辑处理器，总内存约 31.71 GiB，运行前空闲约 13.2 GiB。计时使用一个进程、BLAS 单线程。

- 120 股、1740 对的 N0/N6/M1 合成面板，单面板约 2.61–2.86 秒，包含 DGP、预检、全部配对 DH、Holm。
- 这些较大面板中的逐对 DH 与记录处理约 0.279–0.340 毫秒/对；逐股双 ADF 预检是主要开销。
- 运行中一次资源采样显示主进程当时的峰值工作集约 233 MiB；这不是完整运行或市场规模的峰值内存测量。
- 补充使用同一组输入重复计时，发现 N7 从 0.755 秒变为 5.061 秒，相差约 6.71 倍。运行环境/调度等原因未定位，不把该差异解释为统计机制差异。

## 外推预算

下表是单进程、BLAS=1 的计算预算；没有实际运行这些后续任务。基准来自三个较大计时面板，慢运行情境为基准乘以观测到的同输入墙钟变化倍数。它们不是置信区间或保证上下界。

市场一次的估算为保守统一口径，包含重新执行预检及线性生成开销；实际可复用未变的 v1 预检，且不会生成 DGP，但市场 I/O、输出表和完整规模内存效应尚未计入。GLOBAL 排序开销从小规模线性外推，也可能不同。

未实测 4/8/32 进程吞吐，不能把上述时间除以进程数当承诺。正式长批前应先明确统计规格，并在拟用并行度下短计时；本次没有自动扩大并行或启用远端。最需要额外预算的是市场几何反复模拟，而非单次市场识别。
