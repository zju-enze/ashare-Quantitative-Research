## 1. 研究问题（相对 v1 的修订）

v1 问题：预先限定的同业股票对中，哪些在**价格水平**上具有协整证据。

v2 问题（因采用因子剥离而明确变化）：

> 在预先限定的同 L2 行业股票对中，哪些在**剔除市场与所属 L2 行业公共趋势后的特异性价格分量**上具有协整证据；该证据来自一个对**非平稳波动与序列相关稳健**的检验，并在**全市场族范围（全部有效候选）内按 FWER=5%** 控制？

这是一个比 v1 更窄、也更强的声明：
- **更窄**：剥离公共因子后，只保留个股特异性随机趋势之间的均衡关系。两只股票仅因共同跟随大盘/行业而产生的协整不再计入。经济含义从"配对共同跟随公共趋势"变为"剔除公共因子后的特异性均衡"。

## 2. v2 针对的失效：v1 校准结论的方法学定位

v1 的预定校准（[CALIBRATION_REPORT.md](../../results/CALIBRATION_REPORT.md)）已经把失效点精确锁定，这是 v2 设计的唯一依据：

| 机制 | 本质 | v1 S1 固定 L2-Holm FWER | v1 S2 FWER |
|---|---|---:|---:|
| N0 | 干净全零 | 4.4%–5.1% ✓ | — |
| N2/N3/N4 | 序列相关 / 厚尾 / 平稳 GARCH | 3%–5% ✓ | — |
| **N1** | 高共同趋势占比的近零假设（λ=0.1） | 28.1%–32.0% ✗ | 52.0%–57.0% ✗ |
| **N5** | 后半样本波动突增（方差断点） | 11.8%–13.4% ✗ | 16.6%–22.0% ✗ |
| **N6** | 前四分之一波动高、其后下降 | 31.9%–33.8% ✗ | 53.2%–57.6% ✗ |
| **N7** | 厚尾＋序列相关＋波动突增 | 10.7%–12.6% ✗ | （v1 S2 未纳入） |

两条方法学结论（v1 报告与计划已分别确认，见 [CALIBRATION_REPORT.md](../../results/CALIBRATION_REPORT.md) 与 v1 计划第 6.1、8.3 节）：

1. **失效在边际检验的 size，不在多重校正层。** N0 通过证明 Holm/BF/BH 实现正确、在有效 p 值下控制在 5%。失效只发生在 N1/N5/N6/N7，即 Engle–Granger 残差 ADF ＋ MacKinnon **渐近** p 值赖以成立的条件被违反之处。FWER 随家族规模从 S1 到 S2 暴涨（N1/N6 由约 30% 升至约 55%）是单项 p 值失准的标志性特征——若单项 p 值有效，族内 FWER 应不随家族规模变化。
2. **全市场校正改域不能修复失准的单项 p 值。** 更严的校正域或更小的 α 只减少数量，不恢复真实 size 控制。

因此 v2 的修复必须作用在**边际检验的有效性**与**误差目标的连贯性**两处，而不是加严校正：

| v1 失效机制 | v2 针对性修复 |
|---|---|
| N1：高共同趋势占比的伪协整 | **因子剥离**（§4）：先移除市场与 L2 行业公共趋势，只在特异性分量上检验。公共趋势驱动的伪协整被直接消除。 |
| N5 / N6 / N7：非平稳波动、序列相关、厚尾 | **sieve wild bootstrap**（§6）：以保留时变方差与序列相关的自助分布取代渐近分布，交付在这些机制下渐近有效的推断。 |
| 合并清单无连贯误差保证 | **全市场 FWER**（§6）：对全部有效候选用 Romano–Wolf 步降程序在任意依赖下控制 FWER=5%。 |

## 4. 公共因子剥离（defactor）

### 4.1 因子定义（可观测、留一、确定性）

对每只股票 i，在形成期逐日构造两个 I(1) 公共因子，均为**留一（leave-one-out）**横截面均值，避免个股对自身因子的机械贡献：

- 市场因子：\( M_t^{(-i)} = \dfrac{1}{|U|-1}\sum_{j\in U,\,j\neq i} P_j^*(t) \)
- 行业因子：\( S_t^{(-i)} = \dfrac{1}{|L2(i)|-1}\sum_{j\in L2(i),\,j\neq i} P_j^*(t) \)，其中 \(L2(i)\) 为 i 所属 SW2021 二级行业的 U 内成员集合。

因子仅依赖冻结的 U 成员与 `P*`，计算一次后冻结。记录每个因子序列的构造口径与成员计数。

### 4.2 剥离回归

对每只股票 i，在形成期做一次一阶 OLS：

\[
P_i^*(t) = \delta_{i,0} + \delta_{i,M} M_t^{(-i)} + \delta_{i,S} S_t^{(-i)} + r_i(t),
\]

保留残差 \(r_i\) 作为 i 的**特异性价格分量**，作为后续配对检验的唯一输入。逐股记录 \(\delta_{i,0},\delta_{i,M},\delta_{i,S}\)、R²、设计矩阵秩与条件数、残差均值与样本标准差。

### 4.3 小行业与退化处理

- 当 \(|L2(i)| < K_{\min}\)（冻结 \(K_{\min}=5\)）时，行业因子留一均值不稳健，改用**仅市场因子**剥离（省略 \(\delta_{i,S}\) 项），并以 `defactor_mode=market_only` 标记。
- 市场/行业因子设计矩阵秩不足或近共线（沿用 v1 判据 R²≥1−100√eps、条件数记录）时，按 v1 数值口径标记并保留原因；该股参与的全部配对继承"数值不可用"的终态，不得当作最强发现。
- 留一行业均值在中等及以上家族（S1 的 9 个其他成员、S2 的 29 个、真实市场多数 L2）对配对伙伴的权重为 1/(|L2|−1)，机械相关可忽略且方向保守（轻微压低而非抬高伪协整）；\(K_{\min}\) 阈值处理极小家族的循环问题。逐对剥离（检验某对时同时排除两只成员）作为更重的替代方案记录在案，本版不采用，理由见 [REVIEW_AND_IMPLEMENTATION_V2.md](REVIEW_AND_IMPLEMENTATION_V2.md) §2。

### 4.4 剥离对真值的作用（设计自洽性）

- 对**真协整**对（在模拟 DGP 中为同簇）：两股以成比例载荷共享同一簇趋势 W，剥离 M、S 后残差仍共享 W → 残差协整，功效保留。
- 对 **N1 近零假设**：剥离后每股只剩各自独立的微小特异趋势（λ=0.1）＋平稳噪声 → 残差不协整 → 正确不拒绝。这是 v2 对 N1 的直接修复。

剥离改变了研究问题（§1），这是自觉的、预注册的选择，不得在看到发现数后撤销或改动因子层级。

## 5. 边际统计量：双向 Engle–Granger

对一对 (a,b)，在其特异性分量 \((r_a, r_b)\) 上计算两个方向的 EG 统计量，严格沿用 v1 的 OLS／残差 ADF／统计量定义路径（[src/engine.py](../../src/engine.py) 的 `eg_audit`），仅把输入由价格水平换为剥离残差：

- 方向 A→B：对 \(r_a = \alpha + \beta r_b + s\) 做 OLS，对残差 s 以 `regression='n'`、`autolag='AIC'`、`maxlag=None` 的 ADF 得 \(\tau_{AB}\)。
- 方向 B→A：对称地得 \(\tau_{BA}\)。
- **配对统计量**：\(\tau_{\text{pair}} = \max(\tau_{AB}, \tau_{BA})\)。

EG 统计量在协整下取很负的值；取两方向中**较不极端（更接近零）者**作为配对统计量，等价于要求**两个方向都给出证据**，是对单向伪协整的内置过滤。逐方向保留 v1 的全部审计字段与数值终态（近共线强制零、非有限、秩不足）。任一方向数值不可用，则该对数值不可用（保守），保留家族位置。

**本版不再使用 MacKinnon 渐近 p 值作为判定依据**；\(\tau_{AB},\tau_{BA}\) 仅作为统计量进入 §6 的 bootstrap 程序。渐近 p 值可作对照字段保存，不参与主判定。

## 6. 全市场 FWER：Romano–Wolf 步降 ＋ 公共面板 sieve wild bootstrap

### 6.1 为什么不是"全市场 Holm/Bonferroni 作用于 bootstrap p 值"

全市场 Holm 的最前端阈值为 \(\alpha/M = 0.05/|\text{valid}|\approx 7\times10^{-7}\)。任何重复数 B 可行的逐对 bootstrap p 值都有下界 \(1/(B+1)\)，无法达到该阈值 → 全市场 Holm 作用于 bootstrap p 值将机械地给出零发现。因此**全市场目标必须用直接作用于统计量分布的程序**，这正是 Romano–Wolf 步降：它用 bootstrap 的**极值统计量分布**给出临界值，分辨率只需到 5% 分位，B=999 即足够；同时它利用配对间的联合依赖（共享股票、共享因子）在任意依赖下控制 FWER，并比 Bonferroni/Holm 更有功效。

### 6.2 零假设构造：公共面板 sieve wild bootstrap

被施加的零假设为**全市场无协整**：所有特异性分量 \(r_i\) 各自为 I(1)，彼此间无协整关系。将剥离视为以超一致估计的载荷为条件的固定一阶变换，**自助直接作用于 \(r_i\)，不在自助世界重做剥离**（载荷的超一致性使生成回归元问题为二阶，见 [REVIEW_AND_IMPLEMENTATION_V2.md](REVIEW_AND_IMPLEMENTATION_V2.md) §3）。

每次自助复制 \(b=1,\dots,B\)：

1. 对每只股票取差分 \(\Delta r_i\)，按 AIC（上限 \(p_{\max}=8\)）拟合 AR(\(p_i\))，得白化创新 \(\eta_{i,t}\)。
2. **公共时点 Rademacher 乘子**：对每个时点 t 抽 \(w_t\in\{-1,+1\}\) 各 1/2，对该时点的创新**向量**整体相乘 \(\eta^*_{\cdot,t}=w_t\,\eta_{\cdot,t}\)。同一 \(w_t\) 跨股票共用，既保留横截面同期协方差，又因 \(w_t^2=1\) 保留逐时点方差（即保留 N5/N6/N7 的时变方差与断点形态）。
3. 用各股拟合的 AR 滤子前向重上色，得 \(\Delta r^*_i\)；累加得 \(r^*_{i,t}=\sum_{s\le t}\Delta r^*_{i,s}\)（锚定 0）。各 \(r^*_i\) 为独立随机趋势的 I(1) 序列 → 任意配对不协整 → 全市场零假设被正确施加。
4. 对全部配对计算自助统计量 \(\tau^*_{\text{pair},b}=\max(\tau^*_{AB,b},\tau^*_{BA,b})\)，统计量路径与 §5 完全一致。

### 6.3 Romano–Wolf 步降（α=0.05，FWER 强控制）

设被检验集合为全部**有效候选**（通过 §8 预检且数值可用的对）。观测统计量越负越显著。

1. 第 1 轮：取每次自助在当前候选集合上的**最小**统计量 \(\min_{\text{pair}}\tau^*_{\text{pair},b}\)，其跨 b 的经验分布左侧 α 分位数记为 \(c_1\)。拒绝所有满足 \(\tau_{\text{pair}}\le c_1\) 的对。
2. 从候选集合移除已拒绝对，在剩余集合上重算自助最小统计量分布，得 \(c_2\)，拒绝剩余中 \(\tau_{\text{pair}}\le c_2\) 的对。
3. 迭代直到某一轮无新拒绝。被拒绝对的并集即 **v2 主发现集合**。

该程序在任意依赖下渐近强控制 FWER（Romano–Wolf 2005）。市场运行 B=999；校准内层见 §9。

## 7. 对照视角与可靠性诊断（报告，不作门槛）

与 v1 保持可比，但均**不**作为进入主清单的条件：

- **逐对 bootstrap p 值**：\(p^*_{\text{pair}}=(1+\#\{b:\tau^*_{\text{pair},b}\le\tau_{\text{pair}}\})/(B+1)\)，由单对自助得到；在 L3/L2/GLOBAL 内分别施加 Holm 与 **Benjamini–Yekutieli**（任意依赖下有效的 FDR，适配配对共享股票/因子的强依赖，取代不成立的 BH-PRDS 假设）。GLOBAL-Holm 的 \(1/(B+1)\) 下界限制须在报告中标明。
- **可靠性诊断**（仅对主发现对计算并报告）：形成期前后半 β 稳定性（分半重估，报告重叠）、特异性价差的均值回复半衰期（残差 AR(1)）。这些是披露性诊断，**不**回写主清单，也不作 Stage 1 发现门槛（半衰期等应用资格仍留待第二阶段）。
- Phillips–Ouliaris 等第二族检验不纳入 v2，留作后续版本的可能增强。

## 8. 适用性预检与数值状态（沿用 v1 口径）

- 对**剥离残差** \(r_i\) 施加 v1 的 I(1) 相容预检（水平 ADF p≥0.05 且差分 ADF p<0.05，`regression='c'`、AIC、maxlag=None），作为保守的报告性筛选。预检为渐近口径，仅用于划定被检验集合，主检验的有效性由 §6 bootstrap 承担。
- 家族在预检之前冻结，预检**不缩小**家族；未通过预检或数值不可用的对保留家族位置、不进入被检验集合、不可成为发现，与 v1 完全一致。
- 数值分流（近共线强制零、有限统计量尾部零、非有限、意外异常）沿用 v1 计划第 6.2 节与 [src/engine.py](../../src/engine.py) 的口径与字段。

## 9. 预定校准协议 v2（独立状态，冻结后方可运行）

### 9.1 不变量：机制与面板 DGP 完全沿用 v1

为实现"同一压力、新检验"的对照，**DGP 机制 N0–N7、A0–A5、M0、M1 的公式、参数、种子生成规则、面板构造与真值定义全部沿用 v1**（[src/simulation.py](../../src/simulation.py) 的 `panel`，v1 计划第 8.2–8.4 节），逐字不改。v2 只改变施加于每个面板的**检验**：由 v1 的"价格水平单向 EG ＋渐近 p ＋三域 Holm/BF/BH"换为 v2 的"因子剥离 ＋双向 EG ＋公共面板 sieve wild bootstrap ＋ Romano–Wolf 全市场步降"。

### 9.2 校准阶段

| 阶段 | 人工行业结构 | L3/L2/全局家族规模 | 机制与外层重复 | 用途 |
|---|---|---|---|---|
| S0 | 2 个 L2，各 4 股 | 1 / 6 / 12 | 全 16 机制各 5 次 | 工程冒烟 ＋ 嵌套 bootstrap 吞吐实测 |
| S1 | 4 个 L2，各 10 股 | 10 / 45 / 180 | 全 16 机制 | 主校准 |
| S2 | 4 个 L2，各 30 股 | 105 / 435 / 1740 | 固定 {N1,N5,N6,**N7**,M1} | 规模压力（v2 新增 N7） |
| S3 | 4 个 L2，各 40 股 | 190 / 780 / 3120 | 固定 {N1,N5,N6,N7,M1} | 更大规模压力（v2 新增阶段） |

相对 v1 的两处**故意加强**，均为事前决定、与发现数无关：
- S2 纳入 N7（v1 以 N6 替换 N7、S2 不含 N7）；N7 是厚尾＋序列相关＋波动的组合压力，是现实最相关、v1 在 S1 已失效的机制。
- 新增 S3，在更接近真实最大 L2 家族的规模上施压（v1 S2 的 1740 仍远小于真实最大族；FWER 既随家族规模增长，必须在更大规模上验收）。

外层重复数 \(B_{\text{outer}}\) 与内层自助数 \(B_{\text{inner}}\) 的冻结取值、以及 S0 实测后在**看到任何拒绝率之前**按算力预算调整的修订机制，见 [REVIEW_AND_IMPLEMENTATION_V2.md](REVIEW_AND_IMPLEMENTATION_V2.md) §4。调整只能依据算力、不得依据结果，并须同步重算 MCSE 与冻结记录。

### 9.3 校准指标

对每个机制、每个阶段，计算 v2 **主程序**（Romano–Wolf 全市场步降，作用域为该面板 GLOBAL 全部有效对）的实现误差率：

- 全市场 FWER：各面板"GLOBAL 内是否至少一个真零假设被拒绝"的均值；二元指标 MCSE＝√[r(1−r)/B_outer]，95% Wilson 区间按独立外层面板重复计算。
- 功效（A0–A5）与混合机制行为（M0/M1）：报告无条件与存活条件功效、FDR 型指标，作参考。
- 同时报告 §7 对照视角（逐对 bootstrap p ＋ Holm/BY，三域）的 FWER/FDR 作横向比较，但主判定只认 Romano–Wolf。

### 9.4 验收门槛（v2 通过/失败的唯一判据）

把 v1 的警报判据反转为**验收门槛**：

> 对**每一个**全零机制 N0–N7、在**每一个**已运行校准阶段，v2 主程序的全市场 FWER 的 95% Wilson **下限 ≤ 0.05**（即不显著高于 5%），则该机制通过；全部全零机制通过即 v2 校准验收通过。任一机制 Wilson 下限 > 0.05 即触发验收失败。

通过门槛**不是**对无条件真实市场误差控制的证明（与 v1 同等克制）；它是"N1/N5/N6/N7 等已知失效模式在 v2 下被控制"的证据。若门槛失败，不得据此更换主方法或删除不利机制，须作为 v2.1 重新预注册（§13）。

## 10. 市场运行与 v1 对照

把冻结的 v2 规则应用于冻结的 `formation-2021-2025-v2` 数据：

1. 因子剥离（§4，计算一次并冻结）→ 预检（§8）→ 双向 EG 统计量（§5）。
2. 单次公共面板 sieve wild bootstrap，B=999，施加全市场无协整零假设（§6.2）。
3. Romano–Wolf 步降，α=0.05 → v2 主发现集合。
4. 报告：v2 主发现的完整逐对证据（代码、行业、剥离载荷、双向统计量、Romano–Wolf 轮次与临界值、逐对 bootstrap p、调整结果、数值/尾部状态、可靠性诊断）。
5. **与 v1 对照**：v2 主发现与 v1 110 对的交集/差集/Jaccard，披露有多少 v1 发现在 v2 下存活、多少为 v2 新增。**预期 v2 发现数远少于 110**，这是可靠性的代价，不得据此回调方法。

## 12. 声明范围与限制

- v2 发现＝在冻结样本、因子剥离规格、双向 EG 统计量与 Romano–Wolf 全市场程序下，拒绝"特异性分量无协整"原假设，且在预定压力机制下通过 5% FWER 校准验收（若验收通过）。
- 仍受限于：来源覆盖的沪深存续普通 A 股、北交所未覆盖、SW2021 历史重建非当时归档快照；bootstrap 有效性是渐近性质，有限样本仍以校准诊断为准；通过预定机制不等于无条件真实市场误差控制。
- 因子剥离后关系为特异性均衡，不证明价格水平的永久均衡、未来收敛或交易盈利。第二、三阶段保持 `planned_deferred`。

## 13. 预注册纪律与门槛失败处理

- 本版全部规格在 v2 运行前冻结；冻结后不得为改变发现数调方法。
- v1 的 110 对与全部 v1 证据保留，标为"名义、未校准的候选集"；v2 发现与之并列报告，诚实披露收缩。
- 若 §9.4 验收失败：如实披露，保留 v2 诊断，**不**换主方法、不删机制；任何进一步的稳健化（如逐对剥离、第二族检验、结构断点检验、IV 稳健单位根 [S7]）须作为 v2.1 **重新预注册**，在新一轮识别运行前冻结。
- 工程层面（运行顺序、暂停/恢复、资源、检查点）遵守 [AGENTS.md](../../AGENTS.md)：用户明确暂停的远端阶段须经用户明确要求才恢复；v2 校准的重算力需求须向用户报告预算并请求授权，不得自动启用远端。
- 维护 [ENGINEERING_CHANGES.md](../../ENGINEERING_CHANGES.md)（新编号追加 v2 决策与验证）、`RESEARCH_STATUS.json`（新增 v2 区块，不改 v1 区块）、README（新增 v2 指引行）。

## 14. 参考与方法来源

- Engle–Granger 两步法、残差 ADF 与 MacKinnon 协整临界值：沿用 v1 计划第 17 节与冻结 statsmodels 版本源码。
- wild/sieve bootstrap 单位根与协整、非平稳波动下的有效性：Cavaliere & Taylor（时变方差单位根）、Cavaliere, Rahbek & Taylor（2010 J. Econometrics；2012 Econometrica，bootstrap Johansen）。recursive-design wild bootstrap。

- 任意依赖下的 FDR：Benjamini & Yekutieli（2001）。
- 非平稳波动下 EG 超额拒绝与 IV 稳健方法：Demetrescu–Hanck（DOI 10.1111/obes.12214，v1 计划 [S7]），本版未实施其 IV 方法，列为 v2.1 可能增强。
