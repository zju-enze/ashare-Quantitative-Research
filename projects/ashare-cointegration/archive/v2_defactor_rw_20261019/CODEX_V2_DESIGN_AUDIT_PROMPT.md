# Codex v2 设计独立审稿提示词（实现前，仅评审）

你的角色：A 股同业协整研究第一阶段**稳健重做 v2.0** 的**独立对抗性方法学审稿人**。你的目标**不是**批准，而是**尽力找出 v2 设计中不严谨、会使统计声明失效、或可被更好/更简单/更省算力的方案替代之处**。请带着"默认它有问题，我要证明在哪"的态度评审。可以质疑设计前提本身（包括误差目标与因子剥离这类已定方向），只要给出理由和更优替代。

- 允许读仓库、读 v1 代码与结果、做小规模只读的 sanity 推演或极轻量数值试验来**核实 v2 文档的论断**（例如确认 DGP 结构、EG 路径、FWER 数值）。不要信文档的叙述，核对实际代码与数据。
- 产出以你的**评审回复**为准；如需落盘，只可新建 `V2_DESIGN_AUDIT.md`（仓库根或项目根），不得触碰已有文件。

## 2. 必须深究的高优先级点（最不标准、最吃重的几处）

对下列每一点，判定"严谨/有缺陷/需修正"，并给出具体修法或更优替代：

1. **条件于一阶载荷的 bootstrap（§6.2 / REVIEW_V2 §3）。** v2 对已剥离残差直接自助、**不在自助世界重做剥离**，理由是载荷"超一致"。请审查：当个股与公共因子**并不协整**时，剥离回归是 I(1) 对 I(1) 的**伪回归**，δ 不收敛到有意义的极限、残差载荷是随机的——此时"条件于载荷"是否仍成立？不重做剥离是否低估了一阶估计不确定性，从而使 bootstrap 参考分布偏小、Romano–Wolf 过度拒绝？这是二阶可忽略，还是会破坏 size 控制？给出判断依据与（若需要）修正方案（如在自助中重做剥离、或对因子结构建模后整体自助）。

2. **Romano–Wolf 作用于 Dickey–Fuller 型统计量（§6.3）。** RW 步降的标准理论建立在统计量（中心化后）联合分布可被 bootstrap 一致估计、通常要求渐近枢轴/可正态化。EG 的 τ 是 DF 型、非枢轴、极限依赖冗余参数（且剥离/双向 max 后更复杂）。请审查：以"自助极值统计量分布"做临界值在这里是否有效？是否需要对统计量做 studentize/pivotize，或改用对非枢轴统计量有理论支撑的 bootstrap-FWER 变体？给出结论。

3. **L2 层剥离是否过度移除信号（§4）。** 候选对都在同一 L2 内，而因子又用了 L2 行业均值；若两只股票本身就主导其 L2，留一行业均值里含大量它们自身的信息，剥离可能**抹掉真实的配对协整**，造成功效坍塌或改变所答问题到难以解释。请评估这一张力：L2 剥离 vs L1 剥离 vs 仅市场剥离的取舍，以及它对 N1 修复与对真备择功效的双向影响。

4. **嵌套 bootstrap 的算力可行性（REVIEW_V2 §4）。** 核对冻结初值（S1 1000×399、S2 500×399、S3 300×399）在"每面板需重算全部对的双向 EG × 内层自助 × 外层面板"下的真实量级，判断是否现实；若不现实，提出**不破坏预注册**的方差缩减或加速（公共随机数、对偶乘子、warp-speed 并与完整嵌套在子集对照、仅对通过粗筛的对做高精度等），并说明对 size/功效估计有效性的影响。

5. **验收门槛（§9.4）。** "全部 N0–N7 机制、全部阶段 Wilson 下限 ≤ 0.05 即通过"是否恰当？它偏宽（B=1000 时点估计可达约 0.06–0.07 仍通过）。应否改为点估计 ≤ 0.05、或控制 Wilson 上限、或对跨机制的多重判定做处理？给出建议判据。

## 3. 其余须逐条检查的维度

- **零假设施加是否正确**：公共时点 Rademacher 乘子 + AR 白化/重上色后，是否确实只破坏协整而保留需要保留的依赖（横截面同期协方差、时变方差/断点、序列相关）？AR 筛是否足以刻画真实依赖（MA/长记忆怎么办）？`p_max=8` 是否该随 T 增长？不同股票 `p_i` 不同导致的**公共时点对齐**（取创新的公共时点交集）是否会引入偏差或 bug？
- **留一循环**：按股留一使配对伙伴以 1/(|L2|−1) 权重进入自身因子，`K_min=5` 是否足够？该机械相关在零假设与备择下方向是否一致（会否同时压 size 和功效）？逐对剥离被排除的理由是否只因算力、有无更轻的折中。
- **双向 max 规则**：`τ_pair=max(τ_AB,τ_BA)` 的联合零分布是否被 bootstrap 正确覆盖；两方向强相关时该规则的实际严格度。
- **预检的一致性**：预检仍用**渐近** ADF（在剥离残差上），而主检验改成 bootstrap——预检本身在 N5/N6 下失准会不会错误地把对移出/留入被检验集合，从而污染全市场 FWER 的作用域？是否也该 bootstrap 化预检，或论证其只影响功效不影响 size。
- **v1↔v2 对照的意义**：v2 改了零假设（剥离后特异性协整），与 v1（价格水平协整）是不同问题；110 对的交集/Jaccard 是否仍有可解释性，还是只能作描述性对照？
- **确定性与复现**：两条独立种子流（面板 DGP vs bootstrap 乘子）、AR 选阶的稳定性、S3 新 `stage_id` 的登记、单/多 worker 一致性——有无遗漏或 bug 面。
- **内部一致性**：三份 v2 文档之间（术语、参数、作用域、门槛）有无矛盾；与 AGENTS.md 的暂停/恢复纪律、与 v1"只增不改"的边界有无冲突。

## 4. 可提出的替代/增强（鼓励，但标明取舍）

明确邀请你提出可能**更严谨、更简单或更省算力**的替代，并给出相对本设计的利弊，而非泛泛而谈：

- IV 稳健单位根/协整（Demetrescu–Hanck，v1 计划 [S7]，DOI 10.1111/obes.12214）是否能**直接**在非平稳波动下控 size，省掉或减轻 bootstrap？
- Phillips–Ouliaris 或 bootstrap-Johansen 作为主统计量或第二族确认的性价比。
- 因子剥离用 PCA（Bai–Ng 近似因子）替代可观测留一均值是否更有原理依据、是否值得其复杂度。
- 误差目标：全市场 FWER（用户已选）vs BY-FDR 的功效/可解释性取舍——在"发现数可能个位数"的风险下，是否应至少并列报告一个 FDR 清单作为主/辅。
- 若 v2 在真实数据上几乎零发现，设计上是否需要预设的"信息量兜底"（如报告功效上界、最接近显著的若干对作描述）。

## 5. 输出格式

给出结构化评审：

1. **总体判定**：v2 现状能否直接冻结进入实现？若不能，列出**冻结前必须解决**的项。
2. **分级发现**，每条含：`[BLOCKER|MAJOR|MINOR|ALTERNATIVE]`、问题陈述、为何影响统计声明/可行性/可复现、**具体修法或替代**、预估改动量。按严重度排序。BLOCKER=破坏有效性或预注册纪律；MAJOR=实质削弱声明或不可行；MINOR=改进/补充说明；ALTERNATIVE=值得考虑的另一路线。
3. **最小改动建议集**：若只改 3–5 处就能让 v2 可冻结，是哪几处。
4. 诚实区分"真的统计/工程问题"与"口味/风格"；对把握不足的点标注不确定性，而不是含糊带过。

最终回复直接给出上述评审；如落盘，只新建一个审稿文件，不改动任何现有文件。
