## 1. 因子剥离实现（计划 §4）

### 1.1 因子构造

- 市场因子、行业因子均为**留一横截面均值**，定义见计划 §4.1。按 U 的冻结成员集逐日计算；缺失日不允许（v1 已保证全期连续交易，直接复用 `P*` 对齐后的面板）。
- 行业成员集 \(L2(i)\) 取 SW2021 二级行业在 U 内的成员。单一归属，冲突按 v1 已解决的归属为准。
- 因子计算一次，落盘 `.local/production_v2/.../factors/`，并记录每个 \(M^{(-i)}\)、\(S^{(-i)}\) 的成员计数与构造口径。

### 1.2 剥离回归与数值口径

- 一阶 OLS（计划 §4.2）：设计矩阵 `[1, M^{(-i)}, S^{(-i)}]`（或 `defactor_mode=market_only` 时 `[1, M^{(-i)}]`）。沿用 v1 的秩/条件数/R² 审计与近共线判据（R²≥1−100√eps 记 `near_collinearity`）。
- 残差 \(r_i\) 的数值终态字段与 v1 `eg_audit` 的 `compute_status` 体系一致：`valid` / `numerically_ineligible`（原因细分）。某股剥离数值不可用 → 其参与的全部配对继承 `numerically_ineligible`，保留家族位置，不可成为发现。
- \(K_{\min}=5\) 的小行业回退（计划 §4.3）在配置中显式写明；记录每股实际 `defactor_mode`。

### 1.3 为何按股剥离而非逐对剥离（本版决定）

- 按股留一剥离：每股一次回归，残差为单一对象，**bootstrap 可一次性重算**（§3），算力线性于股票数。
- 逐对剥离（检验某对时同时从因子中排除两只成员）可完全消除配对伙伴进入自身因子的循环，但使"剥离残差"成为逐对对象，bootstrap 需逐对重做剥离，算力乘以配对数，在全市场与嵌套校准下不可行。
- 本版采用按股留一剥离 ＋ \(K_{\min}\) 阈值；中等及以上家族循环项权重 1/(|L2|−1) 可忽略且方向保守。逐对剥离列为 v2.1 可能增强，本版不实现。

## 2. 边际统计量实现（计划 §5）

- 统计量路径逐字复用 v1 `eg_audit` 的 OLS→残差→`adf_audit(resid, "n")`→`EG_stat` 计算，仅把输入 `(a,b)` 换为 `(r_a, r_b)`。保留 v1 全部逐对审计字段，按方向各存一份（后缀 `_AB`、`_BA`）。
- \(\tau_{\text{pair}} = \max(\tau_{AB},\tau_{BA})\)。两方向任一 `numerically_ineligible` → 配对 `numerically_ineligible`。
- **v2 不以 `mackinnonp` 的渐近 p 值做判定**。`p_library` 等渐近字段可作对照列保存，`parameter_valid`/`compute_status` 仍按 v1 口径描述统计量数值可用性。

## 3. Bootstrap 实现（计划 §6.2）：公共面板 sieve wild bootstrap

### 3.1 条件于一阶载荷（为何不在自助世界重做剥离）

剥离是以**超一致**估计的协整型载荷为条件的固定一阶变换（I(1) 对 I(1) 的投影系数以 \(T\) 速率收敛，快于通常 \(\sqrt T\)）。因此自助**直接作用于已剥离残差 \(r_i\)**，不在每个自助面板重做剥离；一阶估计误差为二阶、可忽略。这既正确又把算力从"逐自助逐股重剥离"降到"逐自助重抽残差"。

### 3.2 单次自助面板生成（钉死步骤）

对复制 b：

```
对每只股票 i（在被检验集合所涉及的全部股票上）:
    d_i   = diff(r_i)                      # 一阶差分，长度 N-1
    p_i   = AIC 选阶的 AR 阶, 上限 p_max=8  # 对 d_i 拟合 AR(p_i)
    eta_i = AR(p_i) 的白化创新             # 丢弃前 p_i 个, 记录有效长度
# 公共时点 Rademacher 乘子（跨股票共用同一 w_t）
for t in 有效时点:
    w_t ∈ {-1,+1} 各 1/2
    eta_star[:, t] = w_t * eta[:, t]       # 对创新向量整体乘
对每只股票 i:
    d_star_i = 用 i 的 AR(p_i) 系数前向重上色(eta_star_i)   # 递归滤子
    r_star_i = cumsum(d_star_i), 锚定 r_star_i[0]=0
```

- 乘子 \(w_t\) 对**时点**抽取、跨股票共用，保留横截面同期协方差与逐时点方差（时变波动/断点形态）。
- AR 白化处理序列相关（N2/N7）；\(w_t^2=1\) 保留异方差（N5/N6/N7）。两者叠加即 recursive-design sieve wild bootstrap。
- 创新长度因白化与差分缩短，各股 \(p_i\) 可不同；重上色时各股用各自系数与各自对齐的 \(\eta^*\)。实现须保证所有股票在同一时点集合上共用 \(w_t\)（取各股有效创新的公共时点交集，或按最大阶对齐后统一时点；在 §6 测试中核对对齐正确）。

### 3.3 自助统计量

对每个被检验配对，在 \((r^*_a, r^*_b)\) 上按 §2 同一路径计算 \(\tau^*_{\text{pair},b}=\max(\tau^*_{AB,b},\tau^*_{BA,b})\)。自助世界的数值不可用（罕见）记录并在该次复制中以 `+inf`（最不显著）参与极值统计，不静默丢弃。

## 4. Romano–Wolf 步降实现（计划 §6.3）与算力预算

### 4.1 步降

```
候选 = 全部有效配对, 观测统计量 tau[pair]
B 次自助得到矩阵 TAUSTAR[b, pair]
rejected = {}
repeat:
    active = 候选 - rejected
    m_b = min over pair∈active of TAUSTAR[b, pair]      # 每次自助在 active 上的最显著(最小)统计量
    c   = quantile_left(m_b 的经验分布, alpha=0.05)      # 左侧 5% 分位
    new = { pair∈active : tau[pair] <= c }
    若 new 为空: 停止
    rejected ∪= new
主发现 = rejected
```

- 分位数取左侧经验分位（更负更显著）。B=999 时 5% 分位用第 50 个序位统计量，分辨率充足。
- 市场运行 B=999；校准内层 \(B_{\text{inner}}\) 见 §4.2。

### 4.2 外层/内层重复数的冻结值与"先实测、再按算力修订、绝不按结果修订"

计划 §9 的校准是**嵌套**自助（外层蒙特卡洛面板 × 内层自助）。冻结初值：

| 阶段 | \(B_{\text{outer}}\)（外层面板/机制） | \(B_{\text{inner}}\)（内层自助） |
|---|---:|---:|
| S0 | 5 | 199 |
| S1 | 1000 | 399 |
| S2 | 500 | 399 |
| S3 | 300 | 399 |

- MCSE：二元 FWER 指标 √[r(1−r)/B_outer]。r=0.05 时 S1 约 0.0069、S2 约 0.0097、S3 约 0.0126。门槛判定用 Wilson 下限，须与该 MCSE 一并解读。
- **修订机制**：codex 先跑 S0，实测单面板嵌套 bootstrap 的真实吞吐（含剥离、双向 EG、内层自助、Romano–Wolf），据此估算 S1/S2/S3 的真实耗时与资源。若冻结初值在可用算力下不可行，codex 在**运行主校准之前**、在 [ENGINEERING_CHANGES.md](../../ENGINEERING_CHANGES.md) 与 `experiment_protocol_v2.json` 中记录一次修订后的 \((B_{\text{inner}}, B_{\text{outer}})\)，**修订依据只能是算力预算，不得参考任何拒绝率/发现数**，并同步重算 MCSE。一旦主校准开始，不得再改。严禁"跑到一半按结果调参数凑完整结论"。
- warp-speed 等单抽加速（每外层面板仅一次内层抽样以估计 size）**不作为注册程序**；codex 可在 S0 上将其与完整嵌套在子集对照作为工程核对，但主校准用完整嵌套。

### 4.3 市场运行算力

市场运行是**单次**自助（无外层蒙特卡洛）：B=999 次重抽 2,984 股残差面板、每次重算约 4.2 万有效对的双向 EG。规模与 v1 单阶段校准预算同量级（v1 S1/S2 各约 288 万/348 万 EG；市场约 999×4.2 万×2 ≈ 8,400 万 EG）。按 v1 实测约 300 EG/s/worker，多 worker 并行；给出进度与断点，允许恢复。

## 5. 确定性与种子

- 校准面板 DGP 的种子严格沿用 v1：`SeedSequence([20261018, stage_id, scenario_id, repetition_id])`，机制编号 N0..N7,A0..A5,M0,M1 为 0..15，`panel()` 逐字复用 v1。S3 为新阶段，`stage_id` 取未被 v1 占用的新值（例如 3），在协议中登记。
- bootstrap 的乘子与（如需要）AR 相关的随机性用**独立于面板 DGP** 的确定性种子流：`SeedSequence([20262026, stage_id, scenario_id, repetition_id, bootstrap_index])`（市场运行用固定 `stage_id=-1` 之类的登记值）。所有种子规则写入 `experiment_protocol_v2.json`，单/多 worker 结果必须一致。
- 任一面板生成非有限或首值为零：记工程无效重复并调查，**不静默重抽**（沿用 v1 §8.2）。

## 6. 测试要求（v2 新增，v1 测试全保留）

正式运行前必须通过：

1. **因子与剥离**：合成一个已知因子结构的小面板，核对留一因子计算、剥离残差、`market_only` 回退、\(K_{\min}\) 边界、数值不可用传播。
2. **边际统计量等价**：在同一输入上核对 v2 双向路径与 v1 `eg_audit` 的统计量逐字一致（输入换为残差后），`max` 方向规则正确。
3. **bootstrap 零假设**：构造两条**真协整**的残差序列与两条**独立 I(1)** 序列，核对 (a) sieve wild 自助后配对在自助世界不协整（真协整对的共享趋势未被自助保留）、(b) 公共 \(w_t\) 跨股共用且逐时点方差保留、(c) AR 白化/重上色对齐正确、(d) 固定种子可复现。
4. **Romano–Wolf**：在构造的统计量矩阵上核对步降的单调性（`rejected` 只增）、左分位取法、全真/全假/混合三种极端下的行为；与逐对 bootstrap p＋Holm 在小集合上的关系作对照（不要求相等，只要求可解释）。
5. **校准指标**：核对全市场 FWER、Wilson 下限、门槛判定、MCSE 公式；零拒绝时不得以 MCSE=0 宣称无误差（沿用 v1）。
6. **单/多 worker 一致性**：同输入同种子，单进程与多进程结果一致；记录 worker 数与 BLAS 线程，避免嵌套线程超配（沿用 v1）。
7. **预检与家族不缩小**：核对预检在剥离残差上执行、家族在预检前冻结、未通过对保留家族位置且不进入被检验集合。

人工统计量/状态行测试只验证规则映射，不替代真实 EG/bootstrap 调用。

## 7. 验收门槛与失败处理（计划 §9.4、§13）

- 通过：全部全零机制 N0–N7、全部已运行阶段，v2 主程序全市场 FWER 的 95% Wilson 下限 ≤ 0.05。
- 失败：任一机制 Wilson 下限 > 0.05。如实披露，保留诊断与全部发现，**不**换主方法、不删机制、不放宽样本；进一步稳健化作为 v2.1 重新预注册。
- 通过不等于无条件真实市场误差控制；功效下降、发现数远少于 v1 110 对是预期代价，不得据此回调方法。
