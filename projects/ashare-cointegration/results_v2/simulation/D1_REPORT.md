# V2.1-DH：D1 开发试验结果

完成时间：2026-10-19T22:32:01.031618+08:00。报告时间：2026-10-19T22:35:04.233340+08:00。

**工程执行完成，统计判断仍有不确定性。** 1500/1500 个面板、270000 次 DH 系统检验全部完成；29 项测试及全量配对/汇总核对通过。按预定单侧置信限观察，2 个机制落入严格档、3 个落入容忍档、4 个证据不足，0 个达到明确失败标准。D1 是开发样本，不构成正式校准通过。

最需要保留的限制是慢回复功效：A4/A5（phi=0.99）无条件功效均仅约 0.16%；A2/A3（phi=0.95）约 23%。当前不能声称 DH 7阶已经同时解决错误控制与实用检出能力。

- 15机制各100次，4个L2、每组10股，共40股/180对；每条序列1212期。
- DH两方程联合检验，7个滞后差分向量；名义alpha=0.05；完整180对GLOBAL-Holm。10%仅是最大容忍标准。
- 沿用V1人工DGP，PCG64与SeedSequence([20261018,1,scenario_id,repetition])；repetition为20000…20099，scenario_id保留N1空位。未使用真实价格。
- 每对只执行一次DH，保留未经预检的完整审计；主程序另以ADF门槛生成p=1占位，保留家族全部位置。
- 首批15面板作为D1的一部分保留，后续调用复用15份并新增1485份；没有重抽种子或改变总分母。

## 2. 错误控制开发诊断

FWER分母为每机制100个独立完整面板；一次面板内出现至少一个真零假发现记一个事件。下表L和U分别是单侧95% Clopper–Pearson下界、上界；二者合写不构成95%双侧区间，各机制的界也不声称同时覆盖。严格档要求U≤5%，容忍档要求5%<U≤10%，明确失败要求L>10%；其余为证据不足。

|机制|错误事件/100|FWER|单侧下界L|单侧上界U|D1开发分档|
|---|---:|---:|---:|---:|---|
|N0|2/100|2.00%|0.36%|6.16%|容忍档|
|N2|6/100|6.00%|2.64%|11.50%|证据不足|
|N3|3/100|3.00%|0.82%|7.57%|容忍档|
|N4|6/100|6.00%|2.64%|11.50%|证据不足|
|N5|9/100|9.00%|4.78%|15.18%|证据不足|
|N6|1/100|1.00%|0.05%|4.66%|严格档|
|N7|5/100|5.00%|1.99%|10.23%|证据不足|
|M0|2/100|2.00%|0.36%|6.16%|容忍档|
|M1|1/100|1.00%|0.05%|4.66%|严格档|

N5点估计最高，为9%，上界15.18%；N7点估计虽为5%，上界仍为10.23%，因此不能记为满足10%容忍标准。N2/N4上界约11.50%。这四项需要更多预先规定的独立证据，不能通过删机制、调整门槛或把点估计当通过来解决。

A0–A5全部为真备择，其结构性FWER为零不提供错误控制证据，故不列入此表。M1只有1个面板发生错误，但该面板出现3个错误配对；这里的FWER是1%，不以3/100替代。

## 4. 实际算力与恢复

- 本机4个worker，每个BLAS=1；两次调用的计算计时合计369.91秒，即6.17分钟（约6分10秒，不含首批后人工检查间隔）。
- 首批15面板：7.00秒；恢复后的1485面板：362.91秒。首次启动22:24:39至最终完成22:32:01，包含中间检查间隔。
- 各面板CPU时间合计1440.95秒（24.02 CPU分钟），不含主进程及启动开销。单面板耗时中位数0.916秒，95%分位1.141秒。
- 一次运行中采样：主进程和四个工作进程合计841.59 MiB工作集；系统可用内存14.89 GiB。该采样不是峰值内存或瞬时CPU利用率。
- 本地检查点与源码快照合计201920346字节（约192.6 MiB）。后续不同几何和全市场成本仍未实测；不把本轮四进程吞吐当作C2/C3的速度承诺。
