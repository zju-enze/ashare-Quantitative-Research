# 单因子测试报告

围绕一个选定因子，记录其与后续收益的关系、样本内外表现及稳健性，形成可复现的测试报告。

## 当前状态

2026-10-22 初始化。尚未确定具体因子、接入数据或执行测试；本项目暂无实证结果。

## 待确定的研究设定

- 因子名称、经济含义、计算公式及数据可得时点。
- 数据来源、股票池、样本区间、观测频率及样本划分。
- 缺失值、异常值、标准化和中性化的处理口径。
- 信号形成时点、收益观察窗口、调仓规则及交易成本假设。

## 拟定报告内容

1. 研究问题、因子定义与数据说明。
2. 因子覆盖率、分布和数据质量。
3. IC / Rank IC 与分组收益表现。
4. 分时期、分样本及不同处理口径下的稳健性。
5. 结论、适用范围与局限。

研究设定明确后，再按实际需要添加代码、Notebook、依赖及运行命令，并记录每次执行使用的参数和输出。

## 数据与结果约定

原始授权数据和证券级中间数据保留在本地，遵循仓库根目录的数据管理约定。报告中的数值和结论须对应实际运行记录；分组毛收益与计入交易成本后的表现分别报告。
