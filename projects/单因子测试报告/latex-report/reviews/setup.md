# 审阅设置

2026-10-26按用户本轮指定的nature-reviewer流程执行三份隔离审阅，再由主执行者汇总。三位代理各使用新上下文，不继承撰写对话，不读取彼此报告。相同输入包为本地冻结的latex_review_packet_v1，含16页PDF、TeX、渲染页、锁定汇总与研究方法；没有放入既有审阅或主执行者问题清单。

预先确定的侧重点：

1. Reviewer 1：教材优秀线与统计口径、数值主张的对应。
2. Reviewer 2：图表、中文叙述、定义、读者理解及实际排版。
3. Reviewer 3：研究结论强度、分域与时变解释、可复现性边界。

侧重点不是排他分工，每位仍覆盖完整报告。报告完成即冻结，再作独立编辑算术核对与汇总；原审阅稿不因后续修正而重写，不以共享上下文模拟互盲。
