\section{资料与复现说明}

方法依据为课程\textit{main\_student.pdf}附录书197--200页（PDF211--214页），成本、净值及IC定义另参考书177--183页（PDF191--197页）。BP作为贯穿估值样例采用月末截面。

课程实现复用\path{qfbook.factor.single_test}的MAD、标准化、中性化、设计矩阵和双腿扣费。项目适配部分包括：先冻结信号、预处理与持仓，再连接下期收益；WLS使用连接收益之前计算的标准化暴露；日期索引保留缺月；净值从期初1起算。

与业界常见口径的差异如下。
\begin{itemize}\setlength{\itemsep}{0pt}
\item 账面权益：使用供应商历史日度PB的倒数；业界常用按公告日重建的归属母公司净资产。
\item 基准：内部基准为实际分层股票的等权毛收益，不扣换手成本；行业与市值域基准同样取S样本，与附录的因子非空定义在C4中一致。
\item 外部指数：沪深300、中证500为价格指数，不含分红。
\item 成本：教材只数换手乘双边千分之四，不含冲击成本、涨跌停成交约束、融券费用和税负。
\item 样本：全部 A 股包含CDR，北交所自2021-11-15起纳入；停牌、退市与合并端点按已声明政策估值。
\item 推断：截面$t$采用常规WLS标准误，时间序列推断未作HAC调整。
\end{itemize}
