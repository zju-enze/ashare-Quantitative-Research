## 3. 应保留的现有逻辑

### 教材成本近似

run_single_factor使用持仓集合交集估计换手，并以首期TO=1扣0.004。这符合书178页／PDF192页式4.12–4.13及脚注7，不是必须修复的错误。

它忽略权重漂移、同股再平衡和组规模变化的完整交易量；本项目披露局限即可。严格权重换手只作为有具体目的的可选敏感性，不替换教材主表。

long_short_net先求毛多空差，再减去两条腿各自成本，写法正确。不能改成Q5扣费收益减Q1扣费收益。

### 预处理与WLS

- MAD、行业/总市值OLS残差、WLS控制变量、Rank IC是可复用骨架。
- w_wls先设为流通市值平方根，最小二乘计算再对w取平方根，是权重进入平方损失的正常变换，不是重复开根号错误。
- WLS使用去极值后标准化因子并加入控制变量；IC/分层用中性化残差。不要为了“统一”而擅自改成完全相同的一次回归。
- 需要统一的是信号样本、日期、预处理来源和缺失政策；不是强求三类方法数值相等。

## 4. 为优秀线补充的最小功能

以下是报告层的功能补充，不应被误写成已经存在或已经损坏：

- 保留三个股票池各自完整时序结果；现factor_report仅返回最后一个池的详细结果，需扩为按池映射或等效可追溯结构。
- 从锁定月度结果构造C3年度汇总，显式使用持有月份与部分年度标志。
- 用已冻结的全A残差做C4行业内重分层和D10市值域内重分层，避免默认重新调用run_single_factor导致再次中性化。
- 复用可配置的n_layer扩展D9十层；D8等指标优先复用layer_stats，但核对年化超额、RF、IR定义。
- C4还需要超额回撤、相对胜率、层序排序等，依RESEARCH_SPEC补齐。
- 图形与解释从结果文件生成；可建立轻量图表/报告层，不因缺少官方生成脚本重写整个课程工程。
