## 2. 研究问题、假说和范围

**【用户已确认】** 主因子为 BP，本项目不先比较多个因子的回测成绩再挑选胜者。

**【项目默认，待预检冻结】** 主研究问题为：在同一时期的历史股票池内，控制行业与规模差异后，较高账面市值比是否与下一完整持有期收益呈稳定的正向关系？这种关系在三类股票池、年份、一级行业和市值区间中有何差异？

事前方向假说为正向：BP 越高，未来收益预期越高；因此 Q1 为低因子层、Q5 为高因子层，十层时 Q10 为高因子层。该方向是假说，不是实证结论。不得在看到负向结果后无记录地翻转因子、调换多空腿或删去不利时期。

经济解释可讨论错误定价与风险补偿，以及高 BP 可能反映资产减值、盈利前景弱或财务困境。三类检验主要提供条件关联、方向和适用范围证据；本报告不能单独识别价值溢价的因果机制，不能保证因子持续有效。

**【教材固定】** 回归、Rank IC、分层三类证据须共同报告；可交易性及完整交易系统不属于主流程（书197／PDF211）。分层收益和多空净值是教材约定下的研究结果，不等同于可实际成交的账户收益。

## 4. 时间轴、样本期与年度归属

### 4.1 唯一持有期定义

**【教材固定】** 附录要求下一交易日收盘换仓，即正文口径 B（书197／PDF211；正文书177／PDF191）。

**【项目默认，待预检冻结】** BP 按估值类月频处理；这与教材月频 EP/BP 样例一致。不要因分子涉及财报就自动改为 ROE 等财务质量因子的每年三次截面。

每期必须保留以下实际日期，不能仅以 `ym` 推断时间：

| 字段 | 含义 |
|---|---|
| `signal_date` | 月内最后一个真实交易日；取因子、市值及历史行业等信息 |
| `entry_date` | `signal_date` 后第一个交易日；按收盘价形成教材分层组合 |
| `next_signal_date` | 下一个月最后一个真实交易日 |
| `exit_date` | `next_signal_date` 后第一个交易日；本期持有收益的终点 |
| `holding_month` | `entry_date` 所属年月，用于收益序列展示和年度归属 |

信号在月末收市后按当日资料生成，随后于下一交易日收盘执行。行业事件按计入的**有效日期**匹配，保留原始时分字段但不额外设置15:00发布截点；当日收市后生效的事件可用于该日信号，下一日期才生效的事件不得提前使用。这是日期级研究，不据此声称已重建行业历史发布档案。

同一只股票的目标收益为：

\[
r_{i,t}=\frac{P^{adj}_{i,exit(t)}}{P^{adj}_{i,entry(t)}}-1.
\]

回归、IC、分层与外部指数都必须使用这组起止日。回归和 IC 不能继续使用月末到月末收益而分层单独修正。信号字段只能使用信号时点可获得的信息；下一交易日停牌剔除是附录明确规定的入场状态筛选，不能扩展成按退出日或未来收益是否缺失筛股。

## 6. 预处理、回归与 Rank IC

### 6.1 每池逐期预处理

**【教材固定】** 在每个截面进行中位数 ±5×MAD 去极值；回归暴露采用 Z-score；对去极值后的因子回归于对数总市值和行业哑变量，取残差供 IC 与分层共用（书197／PDF211；原理见书142／PDF156、书153–154／PDF167–168）。

**【项目默认，待预检冻结】** 三个主股票池分别在各自当期分析池内估计截面统计量和中性化回归。不要把三池同时使用全部 A 股预处理残差的另一路径混入主表。C4/D10的域内分析例外按第10节执行。

记缩尾后的因子为 `bp_w`，采用含截距、去掉一个基准行业哑变量的设计矩阵，避免虚拟变量完全共线。中性化为普通最小二乘：

\[
bp^{w}_{i,t}=\alpha_t+\gamma_t\ln(total\_mv_{i,t})+\sum_j\delta_{j,t}Ind_{ij,t}+e_{i,t}.
\]

`e(i,t)` 是 IC 和分层的因子暴露。回归法使用 `bp_w` 的 Z-score 并直接加入行业和规模控制，不要误把 WLS 必须改成对残差单独回归。

**【项目默认，待预检冻结】** Z-score 保持当前实现的截面总体标准差 `ddof=0`。MAD为0、标准差为0、有效因子取值不足、设计矩阵秩不足等情况须显式标记，不能输出无限值或貌似正常的 t 值。

### 6.2 WLS

**【教材固定】**

\[
r_{i,t}=a_t z(bp^w_{i,t})+b_t\ln(total\_mv_{i,t})+\sum_jc_{j,t}Ind_{ij,t}+\alpha_t+\varepsilon_{i,t},
\qquad w_{i,t}=\sqrt{circ\_mv_{i,t}}.
\]

权重指 WLS 目标函数中的权重。若手工变换设计矩阵，乘的是 `sqrt(w)`；不能因为代码出现两次平方根就直接断言权重错误。依据为书189／PDF203、书197／PDF211。

主 C1 沿用经核查的课程 WLS 常规标准误和逐截面 t 值。若另作稳健标准误或均值的时间序列推断，单独标为补充方法，不替换固定主表，也不把“每期 t 值均值”当作“平均因子收益的 t 检验”。

### 6.3 Rank IC

**【教材固定】** 对中性化残差 `e(i,t)` 和同一目标持有期个股收益计算 Spearman Rank IC。

**【项目默认，待预检冻结】** C1 的 `IC_IR = mean(IC) / sd(IC)` 不年化；时间序列标准差用 `ddof=1`。`IC>0`占比的分母为有效 IC 期数。覆盖和有效期数必须同时记录。

WLS、残差 Spearman IC 与等权分层不数学等价。不得把简单 OLS/Pearson 情形的 `IC²=R²` 恒等式直接套用到本报告。

## 7. 缺失收益和异常估值

**【项目默认，待预检冻结】** 缺失目标收益必须先区分数据缺口、入场停牌、持有期或退出日停牌、复权资料缺失以及退市等原因。禁止：

- 在分层前 `dropna(ret_fwd)`，让未来可观测性改变历史成员；
- 用 `mean(skipna=True)` 自动把缺失个股的原权重重分给可观测个股；
- 用 `fillna(0)` 把未知股票收益、未知指数收益或整期缺口变为零收益；
- 因未来退出困难而事后从最初股票池删去股票；
- 把少一段价格的问题改成更长持有期，然后仍标为一个月。

修复数据缺口优先于改样本。真实停牌期间若采用最近有效估值延续，必须有停牌状态与公司行为核实支持，并标为教材级估值近似，不代表退出日能够成交；不能只凭没有行情行就断言停牌。收益整段不得直接赋零。

退市或终止上市样本需要终点估值、退市整理行情或可核实的终止价值信息。若无法核实，不得用无限向前填充掩盖损失，也不得任意设为零或负100%。列明缺口和受影响成员、权重及期数，相关组合主结果暂不通过验收。

回归/IC若需使用收益可观测子样本，必须在形成阶段参数冻结之后进行，并披露有效收益比例。该做法不能自动解决分层持仓收益缺失，也不能让不完整分层净值进入主表。

## 8. 分层、成本与基准

### 8.1 分层

**【教材固定】** 主结果在中性化残差上全局等分五层，每层期初等权（书197／PDF211）。十层扩展用于D9/D10，不替换C2的五层。

**【项目默认，待预检冻结】** 并列值按稳定的股票代码次序打破以得到近似等人数层；记录并列比例和切分规则，不能依赖原始文件的偶然行序。主五层遵循已有不少于50只的计算门槛；单期门槛、取值种数和跳过原因须公开记录，不得静默跳期。WLS另须满足设计矩阵满秩与正剩余自由度。

### 8.2 教材成本近似

**【教材固定，正文给出操作细节】** 保留书178／PDF192的只数换手近似，不擅自升级成完整持仓漂移和交易撮合模型：

\[
TO_{q,t}=1-\frac{|S_{q,t}\cap S_{q,t-1}|}{|S_{q,t}|},
\quad c=0.004,
\quad r^{net}_{q,t}=r^{gross}_{q,t}-cTO_{q,t}.
\]

首期 `TO=1`，按教材扣一份 `0.004`；每期成本计入其后持有期收益。该只数口径是等权换手近似，会忽略价格漂移和成员数变化引起的部分交易量；这是需要披露的模型局限，不能误报为程序错误。

多空每条腿各扣成本：

\[
r^{LS,net}_{t}=r^{gross}_{Q5,t}-r^{gross}_{Q1,t}-cTO_{Q5,t}-cTO_{Q1,t}.
\]

十层时对应 Q10−Q1。不得使用 `Q5_net - Q1_net`。当前 `long_short_net` 的双腿扣费方向应保留。多空净值按 `prod(1+r_LS_net)` 构造，这是附录的计算约定，不额外除以2，也不将其解释为具有唯一资本占用含义的真实融资融券账户。

### 8.3 基准

- **【教材固定】** 内部基准为当期全部分层个股的等权组合；附录对行业基准的原定义为“该行业当期因子非空个股等权组合”（书198–199／PDF212–213）。
- **【项目默认，待预检冻结】** C4实际基准与经过控制变量资格核验后的行业内分层全集S对齐；控制变量缺失的因子非空股票不为基准重新纳入。该处理及其相对附录字面定义的差异须披露，详见第10.1节。
- **【项目默认，待预检冻结】** 内部基准使用与层组合相同的已冻结样本和持有期，以个股毛收益等权计算；按现有课程实现不单独扣基准换手成本。图表写明“分层已扣教材成本，内部等权基准未扣成本”，避免误称两者成本待遇相同。
- 基准按全部股票等权，不是对五层收益简单平均后默认相等；层大小不一致时二者有差别。
- **【教材固定】** D4同时叠加内部基准和沪深300/中证500指数净值；它们须与组合起止日完全对齐。
- **【待核实】** 本地指数行情究竟为价格指数还是全收益指数。若只有价格指数，准确标注；它与含分红调整的个股组合有口径差异，不把该对比解释为已经严格计算指数增强超额收益。主要选股比较使用同样个股收益口径的内部基准。

## 9. 统计量与图表口径

以下汇总教材要求与**【项目默认，待预检冻结】**。D2算术累加由正文书183／PDF197说明，分层/多空净值复利、D5及D6按教材定义；D3累计算子、RF、ICIR年化与否、年化超额、超额回撤和年度归属等具体约定属于项目默认，用于消除歧义并复用已有程序。

| 统计量 | 统一定义 |
|---|---|
| 年化收益 | 对完整连续月频净收益，`prod(1+r)^(12/n)-1` |
| 夏普比率 | `sqrt(12) * mean(r) / sd(r)`；默认无风险收益率为0并明确注明 |
| 月度超额 | `e_q,t = r_q,t_net - r_b,t` |
| 年化超额 | `12 * mean(e_q,t)`；标明为算术年化，不与两条CAGR之差混用 |
| 信息比率 | `sqrt(12) * mean(e) / sd(e)` |
| 最大回撤 | 净值包含期初1；`min(NAV/running_max(NAV)-1)`，以非正数报告 |
| 超额最大回撤 | 默认从相对净值 `NAV_q/NAV_b` 计算相同回撤定义，表注写明 |
| 月胜率 | 多空：净多空收益严格大于0的期数/有效期数；相对胜率：月超额严格大于0的期数/有效期数 |
| ICIR | 月IC均值/月IC样本标准差，不乘 `sqrt(12)` |
| D2 | 月Rank IC算术累加，不复利 |
| D3 | 月回归系数 `a_t` 算术累加，标为累计回归因子收益；不是可交易净值 |
| D5 | 各层扣费净值除以同口径内部基准净值 |
| D6 | 同一连续12期内，分层复利累计收益减去基准复利累计收益；不足12期保留缺失 |
| C3年度收益 | 按第4.3节年度归属，对该年持有期收益复利；多头超额为同年Q5复利收益减去基准复利收益 |

时间序列标准差统一 `ddof=1`；标准差为0或有效期数不足时相应比率记为不可计算，不强填0。C2表中夏普、最大回撤、月胜率对应多空；D8各层夏普与信息比率才是层组合指标。

全样本、年度、滚动窗口和截面统计量不得混用。同一字段在主表、图注和自动解读中必须来自同一份结果对象。

**连续性规则：** 无效月份保留在完整时间索引中并说明原因；禁止删掉月份后把剩余观测按连续月频复利、年化或计算“12个月滚动”。主表须使用经核实的完整连续窗口。若仅能使用另一个连续子窗口，先在不查看收益的覆盖检查中确定并披露，不得事后挑选有利片段。

## 10. 优秀线的分域方法

### 10.1 C4：分行业五层

**【教材固定】** 一级行业内部单独做五层，以行业内当期因子可用股等权组合作为基准；按多头层年化超额排序，列明多头层年化超额、夏普、信息比率、超额最大回撤、相对基准月胜率、各层收益排序、排序与层序的秩相关；统计多头层排名第一或前二的行业数（书199／PDF213）。

**【项目默认，待预检冻结】** C4复用同一期全部 A 股预处理得到的BP中性化残差，再在每个历史一级行业内部重分五层，不重新拟合每行业独立的规模斜率。因子残差取自全市场形成阶段，域内分层不读取未来收益。此选择是项目方法约定，不是附录明确指定的唯一算法。

当行业/市值控制变量缺失时，该股票不能只为了行业基准而重新纳入。行业基准与实际分层全集一致，其与附录“因子非空”表述的差异在方法说明中列明。

### 10.2 D9与D10：十层与市值适用域

- D9：在与全部 A 股五层主结果相同的形成样本、预处理和时间窗口上重分十层，不重新挑选样本。
- D10：按当期**流通市值**将全部 A 股有效分析样本分为等人数的低、中、高三档，再在每档内部按同一份全市场BP残差重分十层。流通市值用于分域参照书140／PDF154；三档和十层的要求见书199／PDF213。
- 每个市值档的基准为该档全部十层样本的等权毛收益，成本与年化超额定义沿用第8–9节。三档的分界、人数、BP覆盖和样本流失须可追溯。
- 这是“先划市值域、域内再按因子排序”的依次分组，不能称为“全市场独立双重排序的交叉组合”。D10的作用是判断适用域，不是寻找最佳规模门槛。

上述分域方案沿用因子值的中性化，不保证每个分层组合在持仓权重上严格行业/市值中性。报告须避免将两者等同。

### 10.3 样本不足与行业可比性

**【项目默认，待预检冻结】** C4每层至少5只，即每行业期初分析样本至少25只；D10每个市值档至少50只，以支持十层每层至少5只。实际每层数和残差不同取值数应满足分层要求；不能机械沿用全局“少于50只或少于20个取值就跳过”的旧条件到所有行业。并列排序不会凭空增加独立因子信息。

这些是最低可计算门槛，不是可靠性保证。必须记录小样本行业及有效期数，不能把其极端指标当成最强行业的确证。

C4先以共同主表窗口为候选。若行业分类更迭或早期样本不足妨碍比较，在不查看行业收益的覆盖预检中确定统一行业比较窗口，并冻结选择理由；仍不满足门槛的行业列为样本不足。不得为得到漂亮排名，逐行业挑选各自最有利窗口。

分域缺期同样保留缺失标记。跨行业排序必须来自可比较的共同窗口；如另列各自连续可用窗口的补充指标，必须附起止年月和期数，不与共同窗口的正式排名混为一谈。
