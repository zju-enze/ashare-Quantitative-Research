## 0. 使用方式与证据规则

- `[ ]` 表示未完成或未验证；只有实际完成、核对并留下证据后，才能改为 `[x]`。
- 每项完成后，填写实际输出路径、检查日期和必要备注；不能仅因函数已经存在就打勾。
- “教材要求”是报告验收内容；“项目质量检查”是保证该内容可信的实现与核对措施；“建议补充”不是附录新增硬要求。
- 本清单中的数学定义用于说明验收口径，不代表任何实测结果。所有示例指标名均不能替代真实输出。
- 如缺资料，写明“未上传”“本地尚未核实”“本地确认不存在”中的准确状态；只有完成本地查找后，才可以断言文件不存在。
- 参考实现、教材样例与用户提供的数据日期检查，均不等于本项目已经通过验收。
- 本项目研究 BP 的历史截面区分能力、适用范围和局限。分层回测不等同实盘可交易收益；本清单不要求扩展成完整交易系统。
- 阶段验收是证据检查，不是自动要求逐阶段人工批准。是否可继续运行由用户当前单轮授权范围决定；在已经授权的范围内，满足证据条件即可继续，不重复请求许可。

## 3. 项目质量检查：成本、净值与统计定义

### 3.1 应保留的教材成本简化

正文书 178 / PDF 192 定义只数换手率：

`TO(q,t) = 1 - |S(q,t) ∩ S(q,t-1)| / |S(q,t)|`，首期 `TO = 1`。

层净收益：`r_net(q,t) = r_gross(q,t) - 0.004 × TO(q,t)`。

这属于教材使用的简化口径。忽略权重漂移、组规模变化引起的额外再平衡，是需要披露的局限，不能不加区分地称为本项目必须修复的程序错误。

- [x] 成本系数为双边 0.004，未误当单边再乘 2；未把同一换手重复扣费。
- [x] 首期建仓处理与教材一致，并在参数说明中记录。
- [x] 各层毛收益、换手率、成本、净收益均可单独检查。
- [x] 多空净收益采用 `Q5_gross - Q1_gross - cost_Q5 - cost_Q1`，或严格等价形式；禁止直接使用 `Q5_net - Q1_net`。
- [x] 保留教材只数换手作为默认；如果另做权重换手敏感性，单独标注并避免与默认结果混表。
- [x] 内部基准、分层组合和外部指数各自是否扣费/含分红写清；不能把口径差异误解释为因子贡献。
- [x] 不因名为“净值”便假定已扣交易成本；图注和绩效表使用的收益序列必须可追溯。

### 3.2 共同的净值与指标约定

正文书 179–180 / PDF 193–194 定义净值为逐期收益连乘，期初净值为 1。

- [x] 所有分层、多空及比较净值使用正确持有期收益复利，并包含期初净值 1。
- [x] 最大回撤计算包含期初净值 1；不能遗漏首期下跌造成的回撤。

- [x] D3 的回归因子收益率累积方式明确标注。附录未明定累加或复利，不能伪称某一种为教材硬要求，也不能把回归系数路径描述为可直接交易的财富曲线。
