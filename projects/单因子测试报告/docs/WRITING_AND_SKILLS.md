## 4. 正文结构与写作顺序

附录结构：摘要（≤1页）、研究背景与因子简介、截面诊断、方法说明、主结果、分年度表现与稳健性、结论。

建议实际写作顺序：

1. 因子定义表、数据与方法；明确哪些口径已核实。
2. 诊断解释及C1–C4、D1–D10的逐项结果说明。
3. 综合讨论：三类证据、时间、行业/市值域、多空两端、覆盖限制。
4. 结论及后续研究边界。
5. 摘要最后完成，只提正文已展示且可追溯的结果。

尚无结果时允许准备结构和方法，不填虚构的数字、正面结论或“预期会显示”的结果段落。

## 5. 每张图表的解读方式

每张图表之后应有一段完整中文解释，按所需信息而非固定句数组织：

- 本图表回答的具体问题；
- 实际观察及支持它的关键数字；
- 与相关图表是否一致、可能原因；
- 样本、时期、成本、模型或数据方面的边界。

数字必须从当次锁定结果读取。模板中的“待填”只能保留在草稿工作记录，最终稿不得出现。不要用看图估数代替读取底层结果。

特定解读要求：

| 对象 | 必须说清楚 |
|---|---|
| D1 | 合格池分母、BP可用分子、覆盖变化；不得把缺失一概称为亏损或负净资产 |
| 行业图/市值诊断 | 截面日期、一级行业范围、原始BP含义；相关均值与同号月份分母 |
| C1/D2/D3 | WLS斜率、截面t、IC均值、方向比例的区别；累计IC不是收益 |
| C2/D8/D9 | 单调性数值依据、两端及中间层形态、成本后比较 |
| D4/D5 | 期初本金与相对基准两种参照；同除基准不改变曲线交叉 |
| D6 | 至少按明确起止年月报告滚动超额均值及失效段；重叠窗口不作为独立样本 |
| D7/C3 | 多空是否集中于少数月份/年份；Q5超额与多空是否同步；部分年度标明 |
| C4 | Q5排名第一/前二的行业数量与可评价行业总数；共同窗口和不足样本 |
| D10 | 市值划域、域内基准、十层数量及适用域；不能据此随意优化市值阈值 |

## 7. 结论强度与三证据不一致

- 正向且较一致时，也只陈述已检验样本、期间和方法下的证据。
- WLS、Rank IC、等权分层的权重和关系形状不同，不要求它们数学等价。
- 多空好而Q5超额弱，先核查低分组贡献；不写成高分组实盘增强已经成功。
- 不显著表示在该设计下证据不足，不能直接推出“效应不存在”；若效应量和不确定性足以支持更强判断，须给出相应依据。
- 中性化前后差异可能反映问题定义改变；不能把所有差异都称为程序修复。
- 方向不稳、近年弱化、小样本或覆盖不足应进入结论。允许“观察”或“剔除”。
- 叙事和润色不得改变数值、显著性、方向、分母、样本期或因果强度。

## 8. 图形与最终审阅

图形改善仅改变呈现，不能改底层数据。统一图层颜色、日期轴、单位、图注和基准说明；合理使用对数轴并明确标注。所有导出图必须实际查看，确认无裁切、重叠、乱码或图例歧义。

最终审阅意见采用：

“位置 → 具体问题 → 证据 → 对结论的影响 → 最小修正 → 是否已解决”。

没有依据的问题不为了凑数量而添加；已解决问题不重复审查。对方法或数据实质缺口，降低结论或保留未完成状态，不能仅通过措辞掩盖。
