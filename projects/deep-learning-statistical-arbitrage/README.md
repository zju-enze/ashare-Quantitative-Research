# Deep Learning Statistical Arbitrage：论文精读与复现

**研究目标：详细理解 Guijarro-Ordonez、Pelger 与 Zanotti 的《Deep Learning Statistical Arbitrage》，梳理其经济逻辑、数学方法和实验设计，并在数据与计算条件允许的范围内尝试复现。**

**当前状态（2026-10-31）：项目已初始化。** 已核对论文首页、摘要与引言，并建立资料入口和研究计划；逐节精读、作者代码核对、数据准备、模型实现和实证复现尚未开展。本目录目前没有可运行的复现程序或本项目实验结果。

## 研究对象与版本

- 作者：Jorge Guijarro-Ordonez、Markus Pelger、Greg Zanotti。
- 研究基准：[arXiv:2106.04028v2](https://arxiv.org/abs/2106.04028v2)。上传日期为 2022-10-07，PDF 首页的稿件日期为 2022-09-25，共 68 个 PDF 页面。
- 用户提供的文件名含有“2026”，但论文内部版本信息对应上述 2022 年稿。研究记录与引用以论文内部版本为准，文件名不作为发表年份的依据。
- 论文实证对象为美国股票日频数据。该研究与仓库中现有 A 股研究分开记录；使用不同市场或替代数据时，应明确记录与原文的差异。

从已读摘要与引言看，论文的方法由三个相互衔接的部分组成：通过因子模型构造残差套利组合，用卷积网络与 Transformer 提取时间序列信号，再将信号映射为服务于经济目标的组合配置。上述为作者的方法概述，尚未由本项目独立验证。

## 研究记录约定

论文报告的结果、我们自行计算的结果及尚未执行的设想应分开记录。公式和实验设定尽量注明原文页码、公式编号或表格编号；笔记同时区分 PDF 页码与论文印刷页码。若只能复现部分方法或使用替代数据，应明确说明覆盖范围。

代码、依赖和执行命令在实际实现时保存在本项目内；原始数据与逐证券中间数据遵循仓库约定留在本地。每次正式实验记录数据范围、时间划分、参数、随机种子、运行环境、命令和结果位置。
